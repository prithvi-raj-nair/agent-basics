## How to use button

Opens a modal with the following text

### Welcome to LLM App visualiser

This webapp lets you visualise the different components that surround an LLM to achieve the LLM app experience that you use.

Quick start

- Chatting and using tools
    - Type into the LLM chat UI to send message
    - Use the ‘+’ to access tools, prompts and resources available to the LLM app
    - Notice the UI for prompt templates
    - Try saying hi to different names and using the prompt template to find
- LLM API calls visualisation - View the inputs and outputs for the LLM API to understand how tool calling and responses are managed
- System activity log - read through linear flow of events across the system to understand how components interact
- Interact with the “Print hello app” directly, a simulation of a third party app and watch how the changes you make there reflects in the tool calls made by the LLM
    - Example - total count of hellos will have latest based on LLM calls as well as UI interaction
- MCP server activity - view inputs and outputs of the server
